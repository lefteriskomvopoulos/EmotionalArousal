# IEEE report (LaTeX, IEEEtran)

`main.tex` (the paper), `refs.bib` (references), `figures/` (four figures, copied from
`results/figures/`; each figure's printed data title is trimmed off in `main.tex`).

**Compile on Overleaf:** zip this folder, then on overleaf.com: New Project → Upload Project →
the zip. The compiler is pdfLaTeX (the default); IEEEtran is built in.

Red bracketed text marks the parts still to write (stage 2: the arousal state and H1–H6). Every
number comes from `docs/EXPERIMENTS.md` and the tables in `data/`.
